# Consignes pour LieluTodo

- Après chaque changement, lancer les vérifications applicables décrites dans `docs/guides/developpement-et-ci.md`.
- Après le push, attendre la fin des builds et des vérifications CI du dernier commit sur la branche modifiée. Corriger les échecs et vérifier le nouveau résultat avant de déclarer le travail terminé.
- Si une vérification reste bloquée, préciser laquelle et pourquoi dans le compte rendu.
